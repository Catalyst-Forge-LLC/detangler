# Review fixtures

Tangled drafts for trying the draft skill. Most have `input.md`.
`expected.json`, where present, names the injected faults. The
skill writes the report; nothing here is a command-line fixture.

`worked-over-note/` is the public sample. The comb of that draft
is on the site: [Sample report](https://detangler.dev/docs/sample-report).

`unwoven-claim/` injects a concept that never joins the section.
`debris/` injects a sentence from another job. A false isolate on
`clean/` is a miss.
`reader-continuity/` holds the continuity cases. `expected.json`
there names types and severities. It is not a model call.

For the app skill, [Dispatch Desk](dispatch-desk/README.md) pairs a
disposable browser app with a separate answer key. Run the review on
the app alone before opening the key.
