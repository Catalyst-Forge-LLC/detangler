title: Report
---

`report.md` is what the author reads. The **detangler** skill writes it.

1. Header: name, word count, section count, timestamp, counts by severity
2. Broken
3. Intentional but verify
4. Judgment calls
5. Reverse outline
6. Argument spine
7. Deferred line notes — a count, not the notes

Every finding has an id, a location, a type, evidence, and an action. Findings without an action are dropped.

Severity:

- **broken** — the document as written is wrong
- **intentional but verify** — plausibly deliberate
- **judgment call** — reasonable people would differ
